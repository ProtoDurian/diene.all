# Observability

This folder holds this service's signal decisions, Grafana dashboards, alerts and runbooks. Rules and folder layout: [Observability Standards](docs/standards/observability/index.md).

- `SIGNALS.md`: the six-gate answers, one block per feature.
- `overview.md`: the system overview every runbook links to.
- `dashboards/`: curated dashboards, added only when Gate 4 says yes.
- `alerts/`: one folder per alert set, added only when Gate 5 says yes.
